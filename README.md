# 🎲 Sistema de RPG Web Portátil

Este projeto é um sistema de RPG nativo para computador, desenvolvido com **HTML, CSS, JavaScript e PHP**, focado em **portabilidade, personalização e acessibilidade**.

A proposta principal é permitir que o jogador leve **seu personagem, sua ficha e o próprio sistema** para qualquer lugar, utilizando apenas **nome de usuário e senha**. Todas as informações ficam armazenadas em banco de dados, eliminando a necessidade de arquivos locais ou instalações específicas.

---

## 🔐 Portabilidade Total

- Acesso completo ao sistema via login  
- Fichas e personagens salvos na nuvem  
- Compatível com qualquer computador com navegador  

---

## 🧾 Sistema de Ficha Integrado

- Ficha digital dinâmica  
- Dados persistidos em banco de dados  
- Atualização em tempo real  

---

## ✍️ Personalização e Anotações

- Sistema de edições de texto integrado  
- Anotações e grifos salvos no banco de dados  
- Experiência altamente personalizável para cada jogador  

---

## 🎯 Objetivo

Criar um ecossistema de RPG digital onde o usuário tenha liberdade, mobilidade e controle total sobre seu conteúdo, sem depender de dispositivos específicos.
